Q

What's new in Python 3.14? Show me a tiny example of the new template strings.

Python 3.14 is mostly about three things: template strings, a free-threaded build that is no longer experimental, and lazily evaluated annotations.

  • t-strings (PEP 750) look like f-strings but give you a Template object instead of a str.
  • Free threading is supported rather than a build-time experiment.
  • Deferred annotations stop forward references from needing quotes.

Here is the smallest useful example:

Python
name = "Que"
page = t"<h1>Hello {name}</h1>"
# page is a Template, not a str: you choose how to render it
