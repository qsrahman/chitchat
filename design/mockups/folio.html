What's new in Python 3.14? Show me a tiny example of the new template strings.

Thought for 4 s
Searched the web for “Python 3.14 release notes” · 3 results

Python 3.14 is mostly about three things: template strings, a free-threaded build that is no longer experimental, and annotations that are evaluated lazily1.

  • t-strings (PEP 750) look like f-strings but give you a Template object, not a str2.
  • Free threading is supported rather than a build-time experiment3.
  • Deferred annotations stop forward references from needing quotes.

Here is the smallest useful example:

python
name = "Que"
page = t"<h1>Hello {name}</h1>"
# page is a Template, not a str: you choose how to render it
